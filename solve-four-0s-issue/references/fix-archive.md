# 「4个0」问题修复归档

本文件由 `solve-four-0s-issue` 技能在问题修复完成后追加，只记录**问题类别**与**解决方案**，作为后续同类问题的修复参考（技能自进化）。

## 写入规则

1. 类别用扫描结果里的规则名，例如 `JS.BASE.EQEQEQ`、`NO_EFFECT`、`MASS_ASSIGNMENT`。
2. 严格脱敏：不得出现项目名/仓库名、文件路径或文件名、代码片段、行号、漏洞 ID、任务或执行链接、分支名、提交者姓名工号，以及任何凭据。
3. 解决方案写成可复用的通用手法（改什么、怎么改、注意什么），不要绑定某一次具体改动。
4. 同一类别已存在时不新增条目，合并进已有条目并更新「修复次数」与「最近更新」。

## 条目格式

```md
### <工具> / <问题类别>
- 解决方案：<通用修复手法，1-3 句>
- 修复次数：<整数>
- 最近更新：<YYYY-MM-DD>
```
